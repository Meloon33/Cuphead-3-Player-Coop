========================================================================
             CUPHEAD 3-PLAYER CO-OP MOD (v1.0.0)
========================================================================

An advanced, balanced, crash-free 3-player co-op modification for
Cuphead & The Delicious Last Course DLC.

Developed through reverse-engineering Cuphead's internal assembly and
Rewired input pipeline over two years of development.
Battle-tested end-to-end with 0 game-breaking bugs across the full game.

------------------------------------------------------------------------
INSTALLATION:
------------------------------------------------------------------------
1. Make sure you have BepInEx 5.4.x (x64) installed in your Cuphead game folder
   (where Cuphead.exe is located).
2. Copy the 'BepInEx' folder from this archive directly into your Cuphead
   game folder, merging with the existing 'BepInEx' folder.
   (The file Cuphead3PCoop.dll should be inside BepInEx\plugins\).
3. Launch Cuphead.exe!

------------------------------------------------------------------------
HOTKEY SHORTCUTS:
------------------------------------------------------------------------
[F1] - Toggle Player 1 Keyboard-Only (frees all gamepads for P2 & P3)
[F2] - Force Join Player 2 (Mugman)
[F3] - Force Join Player 3 (Ms. Chalice / Green Tint)
[F4] - Auto Re-pair Controllers (Cleanly maps P1=KB/Pad1, P2=Pad2, P3=Pad3)
[F5] - Open 1930s In-Game Configuration Menu (Loadout, Modifiers, Stats)
[F6] - Toggle Hardcore Co-op Mode (Instant restart if ghost lost)
[R] / [Left Stick Hold 1s] - Quick Boss Restart without pausing
[V]  - View Boss Victory Scorecard (Damage breakdown, MVP laurels)

For full documentation and source code, visit:
https://github.com/Meloon33/Cuphead-3-Player-Coop
